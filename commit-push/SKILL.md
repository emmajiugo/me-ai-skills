# commit push

- Update the branch with the main branch if the head is \[main\]. If it is a stacked PR, use skill /gh-stack
- Commit and push.
- Conventional commit with a one line commit message
- No co-authored.
- Create a draft PR if it is a new PR, if not, no need.
- Make the PR description concise and straight to the point.
- Use the skill /unslop to make it more human and simple english.
